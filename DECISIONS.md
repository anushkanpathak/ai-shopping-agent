# Decisions

1. Chose Groq API over OpenAI for faster inference and free tier access.

2. Used React + Vite for frontend because of fast development and lightweight setup.

3. Used Express.js backend for simple API integration and routing.

4. Implemented modular route structure for scalability.

5. Used Shopify API for real product data integration.

6. Separated frontend and backend for independent deployment.

7. Stored environment variables in .env files for security.

8. Added .env.example files so judges can understand required configuration.

9. Used Render for backend deployment because of free hosting support.

10. Used Vercel for frontend deployment due to easy React hosting.
